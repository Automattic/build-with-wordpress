Expected import path

  1. Figma plugin exports or receives a generated website artifact.
  2. This runner passes the artifact into a WordPress Playground blueprint.
  3. Playground boots WordPress and PHP in WebAssembly.
  4. Static Site Importer installs from GitHub, reads the static files, and creates WordPress content.
  5. Blocks Engine compiles/imports compatible block structures.

Post-import visual parity and block validation are still future runner work.
