## Core concepts

- **Canonical skills live in `skills/**`.** Generated packages should receive skill updates through `pnpm build`, not by hand-editing copied skill files under `plugins/**`.
- **Generated packages live in `plugins/**`.** They are reviewable artifacts generated by `scripts/build-plugins.mjs` for each supported agent surface.
- **WordPress Studio is the runtime integration.** Generated MCP configs launch `studio mcp` as `wordpress-studio` where the target surface supports MCP.
- **Telemetry is bundled by this repository.** `scripts/wordpress-telemetry-mcp.mjs` is bundled to `dist/wordpress-telemetry-mcp.mjs`, then embedded as generated Node bootstrap arguments for `wordpress-telemetry` MCP server entries.
- **Verification is part of the contract.** Run `pnpm build` and `pnpm verify` before reviewing generated output changes.

## Source evidence used for this documentation

This bootstrap documentation is grounded in:

- `README.md` for repository purpose, supported outputs, commands, testing, and Cursor publishing;
- `package.json` for package metadata and script contracts;
- `skills/**` for the canonical skill inventory;
- `scripts/build-plugins.mjs` for generator layout, output targets, MCP helpers, telemetry bootstrap generation, and surface-specific templates;
- `scripts/build-telemetry-mcp.mjs` and `scripts/wordpress-telemetry-mcp.mjs` for telemetry generation;
- `scripts/verify-plugins.mjs` for verification responsibility;
- `scripts/export-cursor-plugin.mjs` for Cursor export behavior;
- `.github/workflows/skills-agent.yml` and `.github/workflows/developer-docs-agent.yml` for automation lanes;
- generated `plugins/**` outputs for artifact layouts; and
- read-only context aliases `studio` and `wordpress-agent-skills` for Studio MCP and portable Agent Skills packaging evidence.

## Required commands

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm verify
```

Use `pnpm export:cursor -- --dry-run` when validating Cursor export behavior without pushing to the standalone Cursor plugin repository.
