## MCP config contract

MCP-capable outputs include two server entries when their surface supports repository-local MCP configuration:

- `wordpress-studio` launches `studio mcp`.
- `wordpress-telemetry` launches Node with an inline ESM bootstrap generated by `createTelemetryBootstrapArgs()`.

The telemetry bootstrap is intentionally embedded in MCP config arguments. It brotli-compresses the shared `dist/wordpress-telemetry-mcp.mjs` source, decodes it at runtime, pushes `--surface <surface>` into `process.argv`, and imports the server from a `data:text/javascript;base64,...` URL. This keeps behavior local to each generated output without copying a large telemetry bundle into every `plugins/**` directory.

`verifyTelemetryScript()` in `scripts/verify-plugins.mjs` fails if a generated output reintroduces `scripts/wordpress-telemetry-mcp.mjs` copies.

## Manifest and marketplace contracts

- **Codex** writes marketplace metadata at `plugins/codex/.agents/plugins/marketplace.json` and the plugin manifest at `plugins/codex/plugins/wordpress-studio/.codex-plugin/plugin.json`.
- **Claude Code** writes `.claude-plugin/plugin.json`.
- **Cursor** writes `.cursor-plugin/plugin.json` and is exported to the standalone `Automattic/wordpress-cursor-plugin` repository.
- **Factory Droid** writes `.factory-plugin/plugin.json` and `.factory-plugin/marketplace.json` plus command, Droid, and hook files.
- **Pi** writes `package.json` with `pi.skills` pointing at `./skills` and does not include repository-local MCP config.
- **OpenClaw** writes `package.json` with OpenClaw compatibility/build metadata and also keeps `skills/` for ClawHub-compatible publishing.
- **Hermes** writes `plugin.yaml`, `__init__.py` skill registration glue, and `.hermes/config.yaml` as a copyable MCP snippet.

## Verification coverage

`pnpm verify` runs `scripts/verify-plugins.mjs`, which checks:

- every shared skill directory is copied to each expected surface-specific skill location
- plugin manifests have expected names, display names, skill paths, MCP paths, marketplace paths, and schema fields
- MCP configs include both `wordpress-studio` and `wordpress-telemetry` where required
- OpenCode, Kilo Code, Cline, Junie, Gemini, Copilot, Zed, Amp, Devin, Roo Code, Factory, Hermes, Pi, Qodo, OpenClaw, Continue, Conductor, Aider, Cursor, Claude Code, and Codex outputs contain their required files
- generated READMEs include important setup and official-surface guidance where the verifier has explicit phrase checks
- generated outputs do not contain copied telemetry MCP server bundles

When a generated output changes, update `scripts/build-plugins.mjs`, regenerate with `pnpm build`, and update `scripts/verify-plugins.mjs` so the new contract is enforced.
